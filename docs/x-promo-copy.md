它是一个轻量级新闻/热点采集与静态站生成工具，目标很简单：把公开热点信号整理成可发布、可搜索、可复用的内容入口。

2/ 它现在支持：

- 多来源热点采集
- 24h / 3天 / 7天窗口
- 话题去重与排序
- 静态 HTML / RSS / JSON / sitemap
- IndexNow / 百度主动提交
- 反馈接收与 Telegram 每日简报

3/ 我做它的原因是：AI 时代的信息不是更少了，而是更碎了。

真正有用的不是再做一个信息流，而是持续把公开信号整理成可以被人、搜索引擎、AI 搜索和私域渠道理解的结构。

4/ 适合这些场景：

- 个人热点站
- 自媒体选题雷达
- SEO / GEO 实验
- 内部趋势看板
- 多来源新闻聚合原型

没有数据库，静态文件可以直接丢到 Nginx、GitHub Pages、Cloudflare Pages。

5/ 仓库已经清理成可公开版本，生产配置、缓存、日志、密钥都不在里面。
