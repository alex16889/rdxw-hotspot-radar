# RDXW 每日外部分发模板

目的：让搜索引擎和真实用户从外部发现 RDXW 的稳定入口和人工分析页。每天最多发 1-2 条，避免像批量 SEO 外链。

## 每日优先链接

1. 首页：`https://rdxw.cc/`
2. 今日全网热点：`https://rdxw.cc/today-hot.html`
3. 热度指数：`https://rdxw.cc/heat-index.html`
4. 当天人工分析页：替换为当天 `/analysis/...html`
